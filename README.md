# ABM v4.5 — PWA + Google Sheet Sync
## 1) ตั้ง Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิม วางเนื้อหา `Code.gs` แล้วเปลี่ยน `TOKEN` เป็นรหัสผ่านของคุณ → บันทึก
3. **Deploy > New deployment > Web app** — Execute as: **Me**, Who has access: **Anyone** → Deploy → อนุญาตสิทธิ์ → คัดลอก URL (ลงท้าย `/exec`)
4. แก้โค้ดภายหลัง ต้อง Deploy > Manage deployments > Edit > New version
## 2) Host ฟรี
ไปที่ https://app.netlify.com/drop แล้วลากโฟลเดอร์ `abm-pwa` (แตกไฟล์ zip ก่อน) ลงไป จะได้ลิงก์ https เปิดบนมือถือแล้วกด "ติดตั้งแอป"
## 3) เชื่อมในแอป
เมนู **Backup / Restore** → ใส่ URL + รหัสผ่าน → "บันทึกการตั้งค่าและซิงค์"
## ข้อควรรู้
- ข้อมูลเดิมในไฟล์ HTML เก่าอยู่คนละที่กับเว็บใหม่: ให้ **Backup JSON จากไฟล์เก่า → Restore ในเว็บใหม่** ก่อนเชื่อม Sheet
- Sheet เป็นสำเนาข้อมูล: แก้ในแอป ไม่ใช่แก้ในชีต • ใช้ File > Version history ของ Sheet ย้อนกลับได้
- แอปทำงานออฟไลน์ได้ ซิงค์เองเมื่อกลับมาออนไลน์ • ถ้า 2 เครื่องแก้พร้อมกันจะถามว่าจะใช้ข้อมูลฝั่งไหน

## v4.5.1
